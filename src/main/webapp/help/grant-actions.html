The Jenkins permissions to grant temporarily on the one job or folder named above, and on no other item.
  • Configure: change the item's own configuration. For a folder, that is the folder's settings: the window gives no permission on the items inside the folder, but the folder's settings still affect them (for example implicitly loaded Pipeline libraries), and reconfiguring a Multibranch Pipeline or organization folder can create or delete the items it generates. Renaming a folder of any kind needs an administrator (or standing Configure permission on it); a window is not enough.
  • Create: create new items directly inside the folder. Applies only to a regular folder.
  • Delete: delete the job. Applies only to a job.
A request for Create or Delete on an item where it does not apply is refused when you submit it. A window stays with the item it was approved for: once that item is renamed or moved, the window no longer applies.
