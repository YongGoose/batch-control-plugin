The Jenkins permissions to grant temporarily on the one job or folder named above.
  • Configure: change the item's own configuration (for a folder, its settings, not the items inside it).
  • Create: create new items directly inside the folder. Applies only to a regular folder.
  • Delete: delete the job. Applies only to a job.
A request for Create or Delete on an item where it does not apply is refused when you submit it.
