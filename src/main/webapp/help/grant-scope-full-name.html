The full name of the one job or folder the permission window is for, for example team/batch/nightly-report or team/batch. A job or folder of any kind can be named (a Pipeline, a Freestyle project, a folder, a Multibranch Pipeline, ...); once the name is recognised, its kind is shown below the field.

The window covers that item only. It gives nothing on any other item, not even on the jobs and folders inside a folder: to change a job in a folder, request a window for that job.

  • Configure: the item's own configuration. For a job, the job; for a folder, the folder's settings, not the items inside it.
  • Create: only for a regular folder (not a job, a Multibranch Pipeline or an organization folder). It lets you create new items directly inside that folder, not inside a folder nested in it.
  • Delete: only for a job. A folder, Multibranch Pipeline or organization folder cannot be deleted (or moved) through a permission window, because deleting it would also delete everything inside it; ask an administrator.

Renaming needs Configure on the item, or else Delete on it and Create in its folder.
