## FAIL details / defects

**DEF-01 (High) — a refused Build on a job without parameters is a silent failure.**
Steps: requester (or admin) opens `batch-lock`, `batch-cbn`, `batch-throttle` or
`batch-authz` (approval required, no parameters) and clicks **Direct Build (needs
approval)**. Expected (SPEC 6: "차단 시 '승인 필요' 안내와 요청 화면 링크가 표시된다(조용한 실패 금지)",
checklist A-02/B5-01, PR-01): an approval-required message with a clickable link to the
request form. Actual: only Jenkins' generic toast "Failed to schedule build. Reload
the page and try again."; reloading does not help and nothing mentions approval.
The same toast pattern ("Failed.") is all a user gets from Rebuild, Rebuild Last
and naginator's Retry on approval-required jobs. Server state correct (no build).
Screenshots: PR-01-3-requester-batch-lock-toast.png, PR-01-3-requester-batch-cbn-toast.png,
PR-01-3-admin-batch-cbn-toast.png, PR-02-2-refusal-toast.png, PR-02-2b-rebuild-last-toast.png.
This is an E2E-D1-type gap: the REST refusal body carries the guidance, but core's
Build Now/Rebuild buttons submit by script and replace it with their own toast.

**DEF-02 (Medium) — the parameterized refusal page has no link, and points
non-requesters to a 404.** Steps: nobc (Build, no Batch Control permission) or
requester clicks Direct Build on `batch-daily` -> Build. Actual: page titled
"Error", HTTP 400, "Submit a run request at http://localhost:8080/job/batch-daily/batch-control/
and wait for approval." as plain text (not an anchor). For nobc that URL answers
404. Expected: a clickable link (SPEC 6), and guidance that fits a user who may
not request. Screenshot: A-13-nobc-direct-build-refusal.png.

**DEF-03 (Medium) — refused re-runs by other plugins leave no audit record.**
Steps: approved `batch-nag` #1 fails; naginator schedules its retry; requester also
clicks Retry; on `batch-rebuild` requester clicks Rebuild on approved #1.
Expected: SPEC 6 "동일 마커의 재사용(재큐·rebuild 등)은 차단되고 기록된다" /
`MARKER_REUSE_BLOCKED` in history and changes.csv; D-47 "a re-use attempt recorded".
Actual: all refused (no build), but changes.csv gains nothing; the only trace is a
controller log line "Blocked a re-run of job 'batch-nag' that re-uses an earlier
approved or manual run without a new approval". The build page shows nothing about
the refused retry. The integration tests (t_06_25, t_06_33, t_06_34) assert only the
refusal. Screenshots: PR-05-2-failed-build.png, PR-05-3-manual-retry-refusal.png, PR-02-*.

detail reads "... outside the name restriction 'app-2' of grant 20260929-195720-swkb4b (D-40)"

A-19-grant-violation-detail.png; A-19-grep.txt.
