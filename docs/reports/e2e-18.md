`r18/final.py KMDEAS`, but section D already runs E itself. E therefore ran a second time on a request that was
already APPROVED, and timed out waiting for the Approve form (`Locator.click: Timeout 20000ms ... form[name=approve]`).
Both E assertions in the first pass had passed. After the fix the unit passes `KMDAS`, and the `r18` run (same hpi,
fresh JENKINS_HOME) passed 13/13 steps and 36/36 assertions. This is not a product defect.

  - Revert, and Install the Batch Control variant, are pressed on pages that were opened before the strategy changed.
  - Both answer HTTP 400 on core's plain error page with the explanation and no stack trace.
  - The original strategy object is restored afterwards.
- **D/E. Approving with change control off.**
  - approver-1 presses Approve after the administrator has turned change control off.
  - The answer is HTTP 400 on the request's own page, with the explanation "Change control is off, so permission
